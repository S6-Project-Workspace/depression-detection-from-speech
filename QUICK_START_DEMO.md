# 🚀 Quick Start - Depression Detection Demo

## Start the Demo

```bash
streamlit run streamlit_app.py
```

Or use the script:
```bash
./RUN_DEMO.sh
```

## How to Use (3 Easy Steps!)

### 1. Click a Demo Button
Choose any sample to auto-populate:
- 😔 **Depressed (Tamil)** - Sample depressed text in Tamil
- 😊 **Non-Depressed (Tamil)** - Sample happy text in Tamil  
- 😔 **Depressed (Malayalam)** - Sample depressed text in Malayalam
- 😊 **Non-Depressed (Malayalam)** - Sample happy text in Malayalam

### 2. Click "ANALYZE ALL MODELS"
The big blue button will run all 3 models instantly

### 3. View Results
See predictions from:
- **TF-IDF Baseline** - Traditional ML
- **MuRIL Transformer** - Deep learning
- **Enhanced Multimodal** - Text + Linguistic features

Plus a **Consensus Prediction** from all models!

## What You'll See

✅ **Individual Model Results**
- Prediction (Depressed/Non-Depressed)
- Confidence score
- Probability breakdown

✅ **Comparison Table**
- All models side-by-side
- Easy to compare predictions

✅ **Consensus Prediction**
- Final decision based on majority vote
- Clear visual indicator

✅ **Linguistic Analysis**
- POS Tagging
- Dependency Parsing
- Named Entity Recognition
